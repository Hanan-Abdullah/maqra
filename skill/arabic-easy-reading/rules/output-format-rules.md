# Output Format Rules — شكل المخرج

هذا الملف هو المرجع الوحيد لشكل المخرج في الخصائص كلها. أما قواعد المحتوى فمكانها ملفات الخصائص.

## أولًا: قواعد عامة

- أخرج كائن JSON واحدًا فقط، داخل كتلة كود من نوع json، ولا تكتب أي شيء قبلها أو بعدها.
- استخدم أسماء الحقول كما هي في هذا الملف بالإنجليزية حرفيًا، ولا تضف حقولًا غير مذكورة.
- اكتب قيم النصوص بالعربية، إلا الترجمة الإنجليزية للمصطلح.
- لا تنسخ نص المقال في المخرج. اكتب الرموز فقط، ونصوصك أنت: الملخصات والعناوين والنقاط والمعاني والشروح والأمثلة.
- لا تستخدم علامة التنصيص الإنجليزية " داخل أي نص عربي، لأنها تكسر ملف JSON. استخدم بدلها علامتي التنصيص العربية « ».
- لا تكتب أسباب تصنيف الأهمية، ولا أي ملاحظات أو تعليقات.

## ثانيًا: الحقول بالترتيب

اكتب الحقول بهذا الترتيب، لأن كل حقل يعتمد على ما قبله:

1. rulesVersions: أرقام إصدارات ملفات القواعد التي استخدمتها، كما هي مكتوبة في أول كل ملف.
2. units: وحدات القراءة بترتيبها، من خاصية الأقسام. لكل وحدة:
   - from: رمز أول كتلة في الوحدة.
   - to: رمز آخر كتلة في الوحدة.
   - title: عنوان الوحدة.
   - summary: ملخص الوحدة من خاصية ملخص القسم، نص لكل وحدة دون استثناء.
   - question: سؤال الفهم من خاصية أسئلة الفهم، لكل وحدة دون استثناء:
     - text: نص السؤال.
     - options: قائمة من ثلاثة خيارات، والخيار الصحيح أولها دائمًا.
     - explanation: جملة الشرح.
     - sources: قائمة رموز الجمل التي تحمل الجواب، من الوحدة نفسها.
3. summary: الملخص العام، نص واحد.
4. keyPoints: النقاط الرئيسية بترتيب الوحدات. لكل نقطة:
   - unit: رقم الوحدة التي تنتمي إليها النقطة، والعد يبدأ من 1.
   - text: نص النقطة.
   - sources: قائمة رموز الجمل التي أُخذت منها النقطة.
   إذا كان النص وحدة واحدة فقط، فاجعلها قائمة فارغة [].
5. terms: المصطلحات بترتيب أول ظهور لها في النص. لكل مصطلح:
   - term: المصطلح.
   - translation: المقابل الإنجليزي، أو المقابل العربي إذا كان المصطلح مكتوبًا بالإنجليزية في النص. وإذا لم يكن متوفرًا، فاكتب null دون علامتي تنصيص.
   - occurrences: قائمة المواضع. لكل موضع:
     - at: رمز الجملة أو عنصر القائمة.
     - form: الصيغة كما وردت في تلك الجملة.
   - meaning: المعنى.
   - explanation: الشرح.
   - example: المثال.
   إذا لم توجد مصطلحات، فاجعلها قائمة فارغة [].
6. importance: تصنيف كل جملة وكل عنصر قائمة في النص، دون العناوين. المفتاح هو الرمز، والقيمة واحدة من ثلاث كلمات فقط بأحرف صغيرة: primary أو supporting أو secondary.

## ثالثًا: مثال على الشكل

هذا مثال مختصر يوضح الشكل فقط. المحتوى الفعلي يكون كاملًا بحسب النص.

```json
{
  "rulesVersions": {
    "summary": 6,
    "terms": 7,
    "importance": 4,
    "sections": 7,
    "sectionSummary": 7,
    "outputFormat": 5,
    "questions": 1
  },
  "units": [
    {
      "from": "h1",
      "to": "p2",
      "title": "نشوء المقاومة وانتشارها",
      "summary": "تنشأ المقاومة من ضغط انتقائي... وينشرها النقل الأفقي للجينات.",
      "question": {
        "text": "ما دور المضاد الحيوي في نشوء المقاومة؟",
        "options": [
          "ينتقي الخلايا المقاومة الموجودة أصلًا",
          "يُحدث في الخلايا طفرات تجعلها مقاومة",
          "يعلّم البكتيريا كيف تتجنب أثره"
        ],
        "explanation": "يقول النص إن المضاد لا يُنشئ المقاومة، بل يسمح للمتغيرات الجينية الملائمة بالبقاء والانتشار.",
        "sources": ["p1.s3"]
      }
    }
  ],
  "summary": "يتناول النص... ويخلص إلى...",
  "keyPoints": [
    {
      "unit": 1,
      "text": "يؤدي المضاد الحيوي دور عامل انتقاء لا مُنشئ للمقاومة.",
      "sources": ["p1.s1", "p1.s3"]
    }
  ],
  "terms": [
    {
      "term": "التركيز المثبط الأدنى",
      "translation": "Minimum Inhibitory Concentration",
      "occurrences": [
        { "at": "p1.s3", "form": "المستوى المثبط الأدنى" },
        { "at": "p6.s2", "form": "MIC" }
      ],
      "meaning": "...",
      "explanation": "...",
      "example": "..."
    }
  ],
  "importance": {
    "p1.s1": "primary",
    "p1.s2": "supporting",
    "p2.s2": "secondary"
  }
}
```
