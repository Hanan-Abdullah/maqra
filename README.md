# مَقرأ

اقرأ أي نص عربي بيُسر.

مَقرأ يحوّل النص العربي إلى صفحة قراءة ميسّرة: ملخص، ونقاط رئيسية، ووحدات قراءة بعناوين وملخصات، ومصطلحات مشروحة، وتمييز للجمل المهمة، وأسئلة فهم، وجدول محتويات، مع إمكانية عرض النص الأصلي كما كتبه صاحبه.

## المحتويات

- `skill/`: مهارة Claude التي تحلل النص وتبني الصفحة.
- `samples/`: نصوص اختبار مع تحليلاتها.
- `backend/`: الخادم وقاعدة البيانات (قيد البناء).
- `frontend/`: واجهة Angular (قيد البناء).

## تجربة سريعة

```bash
node skill/arabic-easy-reading/scripts/build.js samples/ai.txt samples/ai.analysis.json /tmp/out
open /tmp/out/reading-page.html
```
